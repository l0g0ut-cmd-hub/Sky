# Лаборатория облаков

Офлайн-рендер одной кучевой башни на Python (numpy) той же математикой, что `Shaders/VolumetricClouds.shader`:
форма из сфер шаблона (`puffs.py`), 3D-шум `Art/CloudNoise3D.bytes`, свет (золото/угли солнца, розовое
многократное рассеяние, фиолетовое заполнение, кайма против солнца).

    cd tools/cloudlab && python3 lab.py    # → tower.png: сбоку, против солнца, от солнца

Итерация ~10 с вместо ~10 минут сборки в CI. Подобранные параметры переносятся в `VolumetricClouds.cs`.
